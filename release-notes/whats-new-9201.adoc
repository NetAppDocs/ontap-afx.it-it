= Novità di ONTAP 9.20.1 per i sistemi di storage AFX
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Scopri le nuove funzionalità incluse in ONTAP 9.20.1 che sono disponibili con il tuo sistema storage AFX.


NOTE: Sono disponibili diverse nuove funzionalità per AFX con ONTAP 9.20.1. Alcune di queste sono specifiche di AFX, mentre molte altre derivano da una base di prodotti condivisa. Oltre a esaminare le funzionalità di AFX descritte di seguito, dovresti anche fare riferimento a  https://docs.netapp.com/us-en/ontap/release-notes/whats-new-9201.html["Novità di ONTAP 9.20.1"^].



[[data-protection]]
== Protezione dei dati

[cols="30%,70%"]
|===
| Aggiornamento | Descrizione 


 a| 
Replica da un gruppo di coerenza di origine non SnapLock a un gruppo di coerenza di destinazione SnapLock for SnapVault
 a| 
Puoi replicare da un gruppo di coerenza di origine non SnapLock a un gruppo di coerenza di destinazione SnapLock for SnapVault. SnapLock for SnapVault protegge i gruppi di coerenza replicati da eliminazioni accidentali o dannose.



 a| 
Limiti degli oggetti per SnapMirror active sync per NAS
 a| 
SnapMirror active sync per NAS aumenta il numero di volumi supportati a 600 per le piattaforme AFX (4 x 4).



 a| 
Scopri il disaster recovery sincrono di SnapMirror
 a| 
SnapMirror synchronous aumenta il numero di operazioni di replica a 600 per le piattaforme AFX.



 a| 
Disaster recovery SVM migliorato
 a| 
ONTAP 9.20.1 migliora il disaster recovery di SVM consentendo la modifica di attributi selezionati dei volumi sui volumi di destinazione SVM-DR utilizzando flussi di lavoro standard per la modifica dei volumi con privilegi di amministratore, riducendo la necessità di procedure assistite dal Support. La release estende inoltre il supporto opzionale per la risincronizzazione rapida di SVM-DR ai costituenti di FlexGroup, aiutando le SVM di grandi dimensioni che includono FlexGroup a tornare più rapidamente a uno stato protetto dopo prove di DR, risincronizzazione o flussi di lavoro flip-resync.



 a| 
SnapMirror cloud rispristino in-place sul volume sorgente originale
 a| 
SnapMirror cloud supporta operazioni di rispristino in-place per i volumi FlexVol, consentendoti di eseguire un'operazione di ripristino di uno snapshot cloud direttamente nel volume di origine originale. ONTAP seleziona lo snapshot comune più recente ed esegue un trasferimento incrementale, riducendo il tempo di ripristino.

[[nas]]
== NAS

[cols="30%,70%"]
|===
| Aggiornamento | Descrizione 


 a| 
Implementa il supporto per NormaliseNameInfo nel protocollo SMB di NetApp ONTAP per garantire compatibilità e prestazioni con i client Windows
 a| 
I client Windows possono recuperare i nomi canonici di file e directory con una singola richiesta, riducendo la latenza di apertura dei file e migliorando la compatibilità SMB per desktop, applicazioni e file server aziendali. ONTAP restituisce automaticamente i percorsi canonici per file e directory aperti, evitando ricerche per singolo componente sui client Windows 11 24H2 e versioni successive senza necessità di configurazione aggiuntiva.



 a| 
Supporto per auto UNMAP con VAAI-NAS per consentire space reclamation
 a| 
ONTAP supporta la space reclamation automatica per i datastore NFS tramite il plug-in NFS di NetApp per VMware VAAI. Questo ti aiuta a recuperare spazio dagli intervalli di blocchi VMDK con thin provisioning quando gli host VMware ESXi 9.0 o versioni successive eseguono operazioni UNMAP.



 a| 
Dimensione massima della directory per i volumi ONTAP FlexVol
 a| 
ONTAP migliora le prestazioni delle directory molto grandi, contenenti fino a circa 25 milioni di file, qualificando le dimensioni delle directory fino a 4 GB. I clienti che eseguono carichi di lavoro che generano un numero estremamente elevato di file in una singola directory, come l'addestramento dell'AI, possono trarre vantaggio evitando le penalizzazioni delle prestazioni riscontrate in precedenza con directory di grandi dimensioni. Migliora inoltre la resilienza garantendo che le directory rimangano completamente indicizzate dopo un failover di protezione dei dati, in modo che le copie replicate offrano buone prestazioni anche quando una relazione di SnapMirror viene interrotta. Questa funzionalità è disponibile con i sistemi storage AFX e può essere abilitata su ciascun volume secondo necessità.



 a| 
Supporto per la conversione automatica da SID a ID UNIX
 a| 
ONTAP introduce il supporto automatico per la conversione da SID a ID UNIX per gli SVM connessi a LDAP, consentendo di generare e invertire UID/GID POSIX a partire da SID Windows. Ciò elimina la necessità di gestire manualmente gli attributi uidNumber/gidNumber in Active Directory, riducendo il carico di lavoro amministrativo e contribuendo a garantire un accesso coerente ai file tramite NFS e SMB. Questa funzionalità, in linea con gli standard di settore, è particolarmente utile per i clienti che migrano grandi reti da piattaforme NAS basate su SSSD e che desiderano preservare la coerenza della mappatura delle identità. La funzionalità è disabilitata per impostazione predefinita e configurabile per ogni singolo SVM.

== Networking

[cols="30%,70%"]
|===
| Aggiornamento | Descrizione 


| link:../administer/additional-ontap-svm.html["Estendi FPolicy a NFS 4.2"]  a| 
FPolicy si estende a NFS 4.2 per offrire il monitoraggio delle attività sui file e l'applicazione delle policy all'ultima versione del protocollo NFS supportata da ONTAP. FPolicy monitora gli eventi di accesso ai file NFSv4.2 per supportare casi d'uso di audit, conformità e resilienza informatica. Il monitoraggio avanzato degli attributi di sicurezza offre una protezione e una classificazione dei dati più robuste. Il supporto di NFS con etichette consente risposte basate su policy alle modifiche delle etichette di sicurezza per ambienti di dati classificati e sensibili alla conformità. Usa questa funzionalità per rafforzare audit, conformità e protezione dal ransomware.

[[s3-object-storage]]
== S3 storage a oggetti

[cols="30%,70%"]
|===
| Aggiornamento | Descrizione 


| link:../administer/additional-ontap-svm.html["FPolicy per storage a oggetti S3"]  a| 
FPolicy offre il monitoraggio della sicurezza per i flussi di lavoro degli oggetti S3. Questo fornisce un framework FPolicy unificato per lo storage di file e oggetti, semplificando le operazioni di sicurezza per gli ambienti dati ibridi. FPolicy per gli oggetti S3 offre visibilità sul ciclo di vita degli oggetti per monitorare la creazione e l'eliminazione di oggetti e le modifiche ai tag dei metadati, al fine di soddisfare i requisiti di sicurezza, conformità e audit. Questa funzionalità offre un monitoraggio non invasivo senza influire sulle prestazioni.



 a| 
Dimensionamento flessibile del bucket S3
 a| 
ONTAP supporta una dimensione predefinita configurabile per i nuovi bucket S3. Questo contribuisce a ridurre la necessità di ridimensionare manualmente quando le applicazioni creano bucket tramite l'API S3 senza specificare la capacità. Se non viene configurata alcuna dimensione predefinita, il comportamento di creazione dei bucket rimane invariato.



 a| 
Consenti i bucket NAS S3 OnTAP su FlexCache con origine FlexVol
 a| 
I bucket NAS S3 su volumi FlexCache con origini FlexVol sono supportati a partire da ONTAP 9.20.1. Sono supportate le operazioni S3 su singolo oggetto (PUT, GET, DELETE, HEAD, LIST). I caricamenti multipart non sono supportati perché i volumi FlexVol sottostanti non supportano Granular Data Distribution.



 a| 
Supporta COPY Object per bucket NAS S3 su volumi FC con origine FG
 a| 
A partire da ONTAP 9.20.1, i bucket S3 NAS sui volumi FlexCache supportano le operazioni di copia di oggetti lato server utilizzando le API S3 CopyObject e UploadPartCopy. Puoi copiare oggetti all'interno dello stesso bucket NAS FlexCache o da un bucket S3 NAS supportato da un volume FlexGroup a un bucket NAS FlexCache.



 a| 
Supporto iniziale per il checksum S3
 a| 
ONTAP S3 supporta i checksum CRC-64NVME compatibili con AWS per i bucket NAS S3. Quando un client S3 fornisce informazioni sul checksum per le operazioni di caricamento e multipart supportate, ONTAP convalida e memorizza il checksum e restituisce informazioni sul checksum per le richieste GET e HEAD supportate.

[[security]]
== Sicurezza

[cols="30%,70%"]
|===
| Aggiornamento | Descrizione 


 a| 
Controlli avanzati per le policy di risposta agli snapshot ARP/AI
 a| 
Puoi configurare il criterio di risposta agli snapshot ARP/AI a livello di SVM o di volume per controllare se ARP/AI crea snapshot quando rileva attività anomale. Sono disponibili tre criteri: `alert-with-proactive-and-periodic-snapshot` (predefinito, mantiene il comportamento esistente), `alert-with-proactive-snapshot` (solo snapshot di attacco, nessuno snapshot periodico) e `alert-only` (solo avvisi e registri eventi, nessuno snapshot creato). Dopo un aggiornamento alla versione 9.20.1, il numero massimo predefinito di snapshot periodici passa da 6 a 2 e il periodo di conservazione predefinito passa da 12 a 7 ore, a meno che queste opzioni a livello di nodo non siano già state modificate. Consulta https://docs.netapp.com/us-en/ontap/anti-ransomware/modify-snapshot-options-arpai.html["Controlli avanzati per le policy di risposta agli snapshot ARP/AI"^] per ulteriori informazioni.



 a| 
Miglioramenti del flusso di lavoro della gestione delle chiavi per le SVM dei dati
 a| 
Quando abiliti un gestore di chiavi esterno su una SVM di dati, ONTAP può migrare automaticamente le chiavi di crittografia del volume di tale SVM dal gestore di chiavi con ambito amministrativo al nuovo gestore di chiavi della SVM di dati. Questo semplifica la transizione alla gestione esterna delle chiavi ed elimina la necessità di una fase separata di migrazione manuale nel flusso di lavoro standard.



 a| 
Supporto per IdP, gruppi AD e LDAP come approvatori MAV
 a| 
I gruppi di approvazione MAV possono includere gruppi di provider di identità (IdP), Active Directory (AD) e LDAP (nsswitch) come approvatori, oltre ai singoli amministratori. I tipi di gruppo supportati includono Entra ID, ADFS, gruppi di dominio AD e gruppi LDAP. L'aggiunta o la rimozione di utenti nella directory IdP, AD o LDAP non richiede alcuna modifica alla configurazione MAV. Le modifiche all'appartenenza di un utente a un gruppo entrano in vigore dopo la nuova autenticazione, al successivo accesso dell'utente. Puoi utilizzare il comando security multi-admin-verify registered-operations show per visualizzare tutte le operazioni proteggibili con MAV disponibili sul cluster corrente.



 a| 
Supporto per l'autenticazione SNMPv3 SHA-512
 a| 
ONTAP supporta l'autenticazione SHA-512 per gli utenti SNMPv3. Questo miglioramento ti consente di usare un'autenticazione SNMPv3 più sicura per i client SNMP esterni e per il monitoraggio degli switch, inclusi quelli che richiedono l'autenticazione SHA-512. Per ulteriori informazioni, consulta Configurare gli utenti SNMPv3 in un cluster ONTAP e Configurare SNMPv3 per il monitoraggio dello stato degli switch Ethernet.

Consulta  https://docs.netapp.com/us-en/ontap-systems-switches/switch-cshm/config-snmpv3.html["Configura SNMPv3 per il monitoraggio dello stato di salute degli switch Ethernet"^] per maggiori informazioni.

[[storage-efficiency]]
== efficienza di storage

[cols="30%,70%"]
|===
| Aggiornamento | Descrizione 


 a| 
Ottimizzazione dello scheduler automatico di deduplicazione (ADS)
 a| 
ONTAP migliora le prestazioni di ADS (Automatic Dedupe Scheduler), consentendoti un maggior numero di sessioni di deduplica simultanee per nodo, nonché una limitazione più intelligente e mirata per bilanciare al meglio l'I/O dei client. L'attività di deduplica sui volumi DP (dai trasferimenti di SnapMirror) e le sessioni di deduplica globale vengono gestite insieme alla normale deduplica dei volumi, riducendo la contesa e la crescita dei metadati. Puoi beneficiare di un risparmio in termini di efficienza dello storage, soprattutto con carichi di lavoro misti, senza dover apportare modifiche alla configurazione. Questa funzionalità è abilitata per impostazione predefinita ed è disponibile sui sistemi storage AFX.

[[storage-resource-management]]
== gestione delle risorse di storage

[cols="30%,70%"]
|===
| Aggiornamento | Descrizione 


 a| 
Supporto enterprise AFX a 32 nodi
 a| 
Puoi implementare cluster ONTAP AFX alla scala completa di 32 nodi con supporto completo delle funzionalità enterprise, con capacità pari a quelle precedentemente disponibili solo con implementazioni AFX più piccole. Questo consente ai clienti enterprise, in particolare a quelli che eseguono training AI/ML e pipeline di dati, di creare cluster di storage più grandi e più densi senza rinunciare ai servizi dati enterprise come tiering, protezione dei dati, snapshot e resilienza. Il supporto completo dei protocolli NAS e a oggetti, inclusi NFS, SMB, S3, FlexGroup e FlexCache, è stato convalidato a questa scala, insieme ai flussi di lavoro HA e di recovery, per garantire un funzionamento affidabile man mano che le tue implementazioni AFX crescono.



 a| 
Struttura a FabricPool
 a| 
FabricPool è una funzionalità di ONTAP che sposta i dati tra un tier locale dalle performance elevate e un tier cloud remoto o di capacità a costo inferiore, in base all'attività dei dati. FabricPool è stata formalmente estesa al sistema storage AFX a partire da ONTAP 9.20.1 ed è disponibile anche con 9.19.1 P3. Consente una scala dei dati molto più ampia per supportare carichi di lavoro a uso intensivo di dati. Sebbene l'implementazione di AFX introduca diverse modifiche architetturali, le caratteristiche fondamentali della funzionalità ONTAP rimangono le stesse.



 a| 
FSA - Tempi di accesso alla directory precisi
 a| 
Le scansioni di File System Analytics e la navigazione in System Manager File System Explorer preservano i metadati del tempo di accesso alla directory (atime). Ciò contribuisce a mantenere valori atime accurati per i flussi di lavoro di archiviazione, tiering, conformità e ciclo di vita dei dati.



 a| 
FlexCache Metriche del volume
 a| 
Le metriche del volume FlexCache riportano la quantità di dati e metadati scambiati tra un volume FlexCache e il relativo volume di origine. Sono state aggiunte due nuove proprietà agli endpoint REST esistenti per statistiche e metriche dei volumi di ONTAP che forniscono visibilità sul trasferimento dei dati da FlexCache all'origine e dall'origine a FlexCache. I contatori vengono raccolti automaticamente senza richiedere alcuna configurazione; sono utili per la pianificazione della capacità, l'analisi delle prestazioni, la risoluzione dei problemi di rete e l'analisi del chargeback. Questa funzionalità richiede ONTAP 9.20 o versione successiva su entrambi i nodi, FlexCache e di origine. Per ulteriori informazioni, consulta la documentazione sull'automazione di ONTAP.



 a| 
Ribilanciamento intra-cluster
 a| 
ONTAP introduce due nuove funzionalità di Balanced Placement per aiutarti a mantenere i cluster con prestazioni ottimali, con il minimo sforzo amministrativo, man mano che i tuoi carichi di lavoro e la capacità del cluster si evolvono. Il controllo del posizionamento al momento del provisioning ti consente di indicare, tramite la REST API, se dare priorità alle prestazioni o ai requisiti di spazio quando viene posizionato un nuovo volume. Space Performance Rebalance (SPR) è un processo in background che cerca continuamente eventuali hot spot di prestazioni in sviluppo o pressione sullo spazio degli aggregati nel cluster. A seconda della modalità configurata, SPR consiglia spostamenti correttivi dei volumi tramite notifiche EMS oppure esegue automaticamente gli spostamenti utilizzando le operazioni standard e senza interruzioni di spostamento dei volumi di ONTAP. Per ulteriori informazioni, consulta la documentazione sull'automazione di ONTAP.



 a| 
Supporto per l'eliminazione dei bucket ONTAP S3 contenenti oggetti
 a| 
Gli amministratori possono pianificare l'eliminazione dei bucket contenenti oggetti quando si utilizza una finestra di ripristino basata su un periodo di conservazione configurabile. Ciò consente il ripristino del bucket prima della scadenza della finestra di conservazione. Questa funzionalità riduce l'arretrato delle scadenze e rende la capacità riutilizzabile più rapidamente per carichi di lavoro con elevato turnover.



 a| 
Supporta la migrazione delle SVM dei bucket NAS S3
 a| 
ONTAP 9.20.1 supporta la migrazione di SVM per le SVM che ospitano bucket NAS S3 su volumi FlexVol, consentendo agli amministratori di migrare le SVM senza dover prima rimuovere la configurazione NAS S3.



 a| 
Calcola lo spazio recuperabile sui volumi FlexGroup
 a| 
ONTAP supporta il calcolo dello spazio recuperabile prima di eliminare gli snapshot sui volumi FlexGroup.



 a| 
Miglioramento delle prestazioni per la cancellazione asincrona
 a| 
ONTAP migliora le prestazioni di eliminazione asincrona e accelera space reclamation per i client NAS/SMB. Contatta il tuo NetApp rappresentante per maggiori dettagli.



 a| 
Provisioning automatico di volumi FlexGroup dalle performance elevate
 a| 
ONTAP semplifica il provisioning di FlexGroup con profili di storage che consentono ai clienti di scegliere un container di dati bilanciato o dalle performance elevate per i propri carichi di lavoro, riducendo la necessità per gli amministratori di configurare e dimensionare manualmente i volumi costituenti per soddisfare i requisiti di prestazioni.



 a| 
Supporto NVFAIL con FlexCache
 a| 
Puoi creare relazioni FlexCache con origini abilitate per NVFAIL. Puoi anche abilitare NVFAIL sui volumi cache, indipendentemente dai volumi di origine. Sui volumi di origine o cache in cui si è verificato NVFAIL, ONTAP blocca le letture o le modifiche dei dati, preservando al contempo il write-back dei dati della cache modificati, e le normali operazioni di I/O riprendono dopo il ripristino.

[[system-manager]]
== Gestore di sistema

[cols="30%,70%"]
|===
| Aggiornamento | Descrizione 


 a| 
Supporto per avvisi di scadenza di certificati e password utente
 a| 
System Manager visualizza un avviso di integrità nella dashboard 30 giorni prima della scadenza di un certificato di un cluster o di una macchina virtuale di storage (SVM) e lo aggiorna ogni giorno con il numero di giorni rimanenti prima della scadenza.

Inoltre, se il ruolo associato a un account utente è configurato per gli avvisi di scadenza della password, l'utente riceve un avviso banner nella parte superiore della pagina in System Manager subito dopo l'accesso, a partire da 14 giorni prima della scadenza della password. L'avviso viene aggiornato ogni volta che l'utente accede per mostrare il numero di giorni rimanenti prima della scadenza della password. Puoi configurare gli avvisi di scadenza quando aggiungi o modifichi un ruolo di amministratore.



 a| 
Supporto per ulteriori avvisi AutoSupport
 a| 
System Manager visualizza nuovi avvisi di AutoSupport che possono aiutarti a risolvere i problemi di configurazione di AutoSupport.
